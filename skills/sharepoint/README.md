# SharePoint skills

Add reusable SharePoint skill packages to this folder. Each skill belongs in its own kebab-case folder:

```text
skills/sharepoint/<skill-name>/SKILL.md
```

Start from [`skills/_template/skill-template`](../_template/skill-template) and follow the repository [contribution guide](../../CONTRIBUTING.md).

## Available Skills

- [Export Latest Assignment Submissions](export-latest-assignment-submissions/SKILL.md)
- [Review Assignment Submissions with a Rubric](review-assignment-submissions-with-rubric/SKILL.md)
- [Student Work Misconception Analyzer](student-work-misconception-analyzer/SKILL.md)
