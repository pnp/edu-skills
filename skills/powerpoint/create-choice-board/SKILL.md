# Create Choice Board

Create a student-ready choice board on the current slide or as a short linked slide set. Keep every option aligned to the lesson objective, make the selection rules explicit, and preserve meaningful student agency without inventing learner labels.

## Gather the Instructional Context

1. Identify the subject, grade or learner level, topic, learning objective, available time, materials, and expected student response or product.
2. Use selected slide content, speaker notes, educator-provided sources, or the educator's prompt as the factual basis.
3. Prefer a Microsoft 365 Teach lesson plan when one is selected, attached, or referenced. Read its title, Overview, Standards, Objectives, Materials, and Lesson Outline before creating tasks.
4. When using a Teach lesson plan, align the board to one stated Objective or one coherent set of closely related Objectives. Use only materials and source content available in the plan or presentation.
5. Ask for missing information only when the topic, learner level, or intended objective cannot be inferred. Use the defaults below for optional choices and report them.

**Source accuracy:** do not invent facts, standards, quotations, source claims, required materials, answer content, or lesson constraints. Mark missing information for educator review.

## Default Board

When the educator does not specify a format, create a 3x3 board with nine concise tasks and the rule `Choose any 3`. Design the nine tasks so a reasonable set of three fits the available work time. If no duration is supplied, assume one class period and report the assumption.

Do not require a tic-tac-toe line unless the educator requests that rule. A line-based rule can force an unintended combination of tasks and reduce meaningful choice.

## Choose the Board Structure

Select the smallest structure that provides useful choice:

- **2x2 board:** four short options for younger learners, brief practice, or limited time.
- **3x3 board:** nine options for a full lesson, homework menu, review cycle, or multi-day task.
- **Must Do / Choose / Extension:** required foundation work plus a bounded choice and optional challenge.
- **Tic-Tac-Toe:** nine tasks where students complete a row, column, or diagonal. Use only when every valid line is balanced for time, rigor, materials, and objective coverage.
- **Learning menu:** grouped options such as appetizer, main task, and extension, with an explicit number required from each group.
- **Pathway board:** ordered stages with limited choice inside each stage. Use when prerequisite knowledge or task sequence matters.

Use one board unless the number of tasks, reading load, or required detail makes a linked task-slide format more readable.

## Design the Choices

1. Start from the learning objective and required evidence of learning. Every required path must provide enough evidence to evaluate that objective.
2. Vary how students engage or demonstrate understanding through formats such as:
   - Explain or summarize
   - Solve and justify
   - Compare or classify
   - Analyze supplied evidence
   - Create a model, diagram, or representation
   - Apply the concept to a new example
   - Evaluate a claim or correct a misconception
   - Discuss, rehearse, or teach using clear accountability
   - Reflect or make an evidence-based connection
3. Keep choice sets reasonably comparable in time, cognitive demand, required materials, and grading effort. Label a task as `Challenge` or `Extension` when it intentionally demands more.
4. Write each tile as a direct student action. Include the product, amount, response location, and success condition when these are not shared by the whole board.
5. Keep essential disciplinary vocabulary and factual meaning intact. Add concise definitions, examples, sentence frames, or organizers when supported by the requested learner needs.
6. Do not assign tasks by supposed visual, auditory, reading/writing, or kinesthetic learning styles. Do not infer ability, disability, language level, or preference from student identity.
7. Do not make the easiest-looking task a low-value decorative activity. Coloring, copying, or searching for pictures is insufficient unless it produces evidence tied to the objective.
8. Do not require students to disclose sensitive personal experiences or circumstances in a public product.

## Write the Selection Rules

Place the rule above the board in plain language. State:

- How many tasks students must complete
- Whether any task is required
- Whether choices must come from different rows or categories
- Whether students may work independently, with a partner, or in a group
- Where work is recorded or submitted
- Available time and due date when supplied
- What students should do after completing the requirement

Test every allowed combination. No valid path may omit the objective, depend on unavailable materials, exceed the intended time, or accidentally require substantially more work than another path.

## Build the Board

1. Preserve the current Slide Master, assigned layout, title placeholder, theme colors, theme fonts, margins, branding, and slide size.
2. Use native editable shapes and text. Do not flatten the board into an image.
3. Give the instructions and selection rule a stable area above or beside the grid. Keep them separate from the task tiles.
4. Use equal tile dimensions within each task group. Keep padding, heading position, and content alignment consistent so one option does not appear preferred by accident.
5. Use short task titles and concise directions. When a tile needs more than a few lines, use a linked task slide rather than shrinking text.
6. Add simple labels or familiar icons only when they help students scan task type, materials, grouping, or estimated time. Pair every icon and color with text.
7. Show special requirements such as `Partner`, `Headphones`, `Teacher check`, `10 minutes`, or `Extension` consistently across tiles.
8. Use restrained category colors with sufficient contrast. Do not use decorative imagery, gradients, 3D effects, or dense ornament that competes with the tasks.
9. Put answer guidance, accepted variants, facilitation notes, differentiation rationale, and source details in speaker notes.

## Optional Linked Task Slides

Use a static one-slide board by default. When the educator requests interactivity or tiles need additional instructions:

1. Create one detail slide per task or per complex task. Retain the presentation theme and repeat the task title, directions, expected product, time, materials, and success criteria.
2. Link each board tile to its matching task slide with a standard PowerPoint hyperlink.
3. Add a visible `Back to Choice Board` control on every detail slide.
4. Test every tile link and every Back control in Slide Show mode before completion.
5. Keep the board understandable when printed or exported to PDF by including enough information on each tile to identify the task.
6. Do not add macros, VBA, add-ins, external game engines, or unsupported persistent completion tracking.
7. Do not imply that PowerPoint automatically records selected or completed tasks. Add a printable checklist, student planning slide, or educator-managed tracking method when requested.

## Optional Student Planning Slide

When the activity spans multiple tasks or days, add an editable planning slide with:

- Student name or identifier field
- Chosen task numbers or titles
- Planned order
- Materials or partner needs
- Completion checkboxes
- Reflection or submission confirmation

Keep the planning slide generic. Do not prepopulate student names, accommodations, diagnoses, or private learner information.

## Accessibility and Classroom Quality

- Keep tile text readable from the intended viewing distance. Use linked slides or fewer choices instead of reducing text excessively.
- Use sufficient contrast and never rely on color, icons, or grid position alone to communicate category, requirement, or difficulty.
- Add descriptive alt text to meaningful images, icons, and interactive controls.
- Maintain a logical reading order: title, selection rule, shared directions, then tiles left-to-right and top-to-bottom unless the board defines another explicit path.
- Make interactive tiles and Back controls keyboard-orderable with generous click targets.
- Keep all essential instructions available in edit view, Slide Show, printed handouts, and PDF export.
- Avoid unnecessary animation, sound, and motion that delays task selection.

## Validation

Review the completed board at fit-to-window and, when linked, in Slide Show mode.

1. Confirm the topic, learner level, objective, materials, response format, and time match the educator's source or reported assumptions.
2. When using a Teach lesson plan, confirm the board aligns to a stated Objective and uses only supported lesson content and materials.
3. Confirm every task is accurate, student-facing, actionable, and tied to the stated objective.
4. Test every allowed choice combination for objective coverage, comparable workload, available materials, and completion within the intended time.
5. Confirm the selection rule states the number required, required tiles or categories, grouping expectations, response location, timing, and next step when applicable.
6. Confirm no task relies on unsupported learning-style labels, inferred learner traits, sensitive disclosure, or low-value busywork.
7. Confirm no tile, instruction, image, icon, or label is clipped, overlapped, distorted, or too small.
8. Confirm contrast, alt text, reading order, keyboard access, and print/PDF comprehension.
9. If linked task slides are used, test every tile and every `Back to Choice Board` control in Slide Show mode.
10. Confirm the deck does not claim to track completion automatically unless a functioning supported mechanism was explicitly added and tested.
11. Report the board structure, selection rule, objective, task count, linked-slide mode, planning-slide mode, source material used, assumptions, and any content still needed.
