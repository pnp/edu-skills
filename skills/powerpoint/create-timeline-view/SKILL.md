# Create Timeline View

Create a clear, classroom-ready timeline on the current slide. Use native PowerPoint shapes and the presentation's existing theme so the timeline remains editable.

## Gather the Events

1. Work on the current slide unless the number of events requires continuation slides.
2. Use selected text, an existing event list, speaker notes, or information supplied by the educator. Do not invent dates, event order, descriptions, images, or historical claims.
3. For each event, identify:
   - Date, year, period, step number, or sequence label
   - Short event title
   - One concise sentence or up to two short bullets
   - Optional image already supplied or explicitly requested
   - Optional source or attribution
4. Preserve uncertainty in dates with labels such as `c. 1450`, `Early 1900s`, or `[Date TBD]`.
5. If event order, timeline direction, or essential dates are unclear, ask one consolidated set of questions before building.

## Choose the Layout

- Use a horizontal timeline for two to six short events.
- Use a vertical timeline for five to eight events, events with longer descriptions, or slides with portrait-oriented images.
- Use continuation slides for more than eight events or whenever readable event cards will not fit. Repeat the timeline title and show the covered date range on each continuation slide.
- Use equal spacing by default for categorical periods, instructional steps, or chronologies where exact elapsed time is not the teaching point.
- Use proportional spacing only when the actual time gaps matter. Label intentional gaps clearly and do not imply equal time intervals when they are unequal.
- For timelines crossing BCE/CE, negative/positive values, or non-Gregorian systems, preserve the source convention and make the transition explicit.

## Build the Timeline

1. Preserve the current Slide Master, assigned layout, theme colors, theme fonts, margins, and title placeholder. Do not create a new theme or flatten the slide into an image.
2. Add one simple timeline spine with a clear reading direction. Use a subtle arrow only when direction would otherwise be ambiguous.
3. Add one marker per event. Align markers precisely to the spine and keep spacing visually consistent with the chosen equal or proportional scale.
4. Connect each marker to its event card with a short line. Avoid crossing connectors.
5. Alternate cards above and below a horizontal spine only when this improves space and keeps the reading order obvious. Keep cards on one side when the event count is low.
6. Each event card should contain the date or sequence label, a short title, and concise supporting text. Keep date styling consistent and make titles more prominent than descriptions.
7. When images are supplied, use one meaningful image per event at most. Crop consistently, preserve aspect ratio, and keep images secondary to chronology. Do not use decorative stock images that add no instructional value.
8. Add brief image credits or event sources in speaker notes unless the educator requests visible citations.
9. Group each marker, connector, card, and image when practical so the timeline remains editable without elements drifting apart.

## Density and Readability

- Prefer fewer, readable events over fitting the full lesson onto one slide.
- Keep event cards equal in width within a slide unless one event is intentionally emphasized.
- Do not use tiny text or shrink body text below the presentation's normal readable size. Shorten text or add continuation slides instead.
- Keep all text inside its card with no clipping, overlap, or awkward single-word lines.
- Keep images large enough to interpret and do not crop away the subject of the image.
- Avoid unnecessary gradients, decorative illustrations, 3D effects, and thick ornamental lines.
- Use one accent color for markers and restrained secondary colors for categories. Do not encode category or significance by color alone; add a label, icon, or pattern.

## Optional Teaching Enhancements

Add these only when requested or clearly supported by the lesson:

- Era or phase bands behind the spine
- Category labels or a compact legend
- A `You are here` marker for a current event
- A comparison row for two parallel histories
- A highlighted turning point with a short evidence-based explanation
- An interactive click-to-reveal mode using native trigger animations

### Optional Interactive Mode

Use a static timeline by default. When the educator requests interactivity:

1. Keep every date marker and date label visible when the slide opens.
2. Make each marker or date point the trigger for its own event card and optional image. Clicking one point must reveal only the content associated with that event.
3. Use a simple `Appear` or short `Fade` entrance. Do not use motion paths, spins, or decorative transitions.
4. Keep revealed content visible so the class can build the chronology event by event. Do not require a second click to hide it, and do not use macros or VBA.
5. Add a short visible cue such as `Select a date to reveal the event` and make interactive markers visually distinguishable without relying on color alone.
6. Set triggers on generous click targets that include the marker and date label when practical. Do not place transparent targets over adjacent events.
7. If the educator requests a guided reveal rather than free exploration, use ordinary click-order animations in chronological order instead of per-marker triggers.
8. Keep all event content present in the PowerPoint file, in logical reading order, and visible when printed or exported to PDF. Interactivity must enhance the timeline rather than become the only way to access its information.

## Accessibility

- Add descriptive alt text to every meaningful image and icon.
- Use a logical reading order: title, timeline direction or range, then events in chronological order.
- Ensure date labels and event titles have sufficient contrast.
- Do not rely on position or color alone to communicate chronology, category, or importance.
- Keep the timeline understandable when printed or exported to PDF.

## Validation

Review the completed slide at fit-to-window and in Slide Show mode.

1. Confirm every event is present once and in the correct chronological or instructional order.
2. Confirm dates, titles, descriptions, images, and sources match the educator's content.
3. Confirm spacing accurately represents either equal intervals or proportional elapsed time.
4. Confirm no card, connector, image, or label overlaps, clips, crosses another event, or extends beyond the slide.
5. Confirm images are consistently cropped and remain recognizable.
6. Confirm the reading order, contrast, and alt text are accessible.
7. Confirm continuation slides use consistent styling and clearly communicate their date ranges.
8. If interactive mode is used, test every marker in Slide Show mode and confirm that it reveals only its associated card and image, click targets do not overlap, and the visible interaction cue is accurate.
9. Report the layout used, event count, continuation slides created, proportional or equal spacing choice, interaction mode, and any missing content.
